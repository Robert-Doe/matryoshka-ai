1 · Tokenization — text becomes numbers

py module_08_nlp\tokenize_demo.py

✅ Watch BPE discover "phish"

Subword tokenization (what GPT/Claude use) merges frequent character pairs. It finds phish as a reusable unit so phishing/phisher/phished share it. Every prompt becomes integer token IDs — and token count is what you're billed for and what fills the context window.

2 · Embeddings — meaning as geometry

py module_08_nlp\embeddings_demo.py

✅ Meaning emerges from context

Built from scratch (co-occurrence + SVD), the vectors put attacker near hacker and cat near dog — with no meanings ever provided. Cosine similarity (Module 02) finds neighbors. This is the input layer of every LLM.

3 · A language model that generates

py module_08_nlp\tiny_bigram_lm.py

A bigram model learns P(next word | current word) by counting, then generates text by sampling one token at a time — autoregressive generation, exactly how an LLM writes. Its flaw: it only sees the last word. Fixing that is why transformers exist.

4 · Attention — the transformer's heart

jupyter notebook module_08_nlp\attention_intuition.ipynb

Computed by hand on a 4-word sentence: each word issues a Query, every word offers a Key, their dot-product (Module 02!) becomes an attention weight via softmax, and the output blends every word's Value. This lets any word pull meaning from any other — solving the bigram's blindness.

🛡 Security lens — prompt injection

Attention operates over the entire context, including text a user or document injects. The model attends to malicious hidden instructions the same way it attends to trusted ones — the mechanistic root of prompt injection. You'll defend against it in Module 10.

5 · The full picture

prompt → tokenize → embed → [transformer layers: attention + feed-forward]
       → predict next token → sample → append → repeat

You've now built or hand-computed every box. That's the whole demystification.
