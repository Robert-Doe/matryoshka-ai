Generative AI & LLMs in Practice

Stop building models, start building WITH them. Prompting, structured output, RAG, and agents — the four capabilities behind most real AI apps.

⏱ ~2 hrs🔌 anthropic SDK 🛡 prompt injection

Setup (one time)

pip install anthropic scikit-learn
:: get a key at https://console.anthropic.com, then:
setx ANTHROPIC_API_KEY "sk-ant-..."   (reopen your shell after)

Default model is claude-opus-4-8. While experimenting, set MODEL=claude-haiku-4-5 to spend far less. Every script prints a clear message and exits cleanly if the key or package is missing — nothing crashes.

1 · The model is an API

py module_10_genai\call_claude.py "Explain gradient descent to a 10-year-old"

Send text, get text back, watch the token count. That's the entire interface. The job shifts from training a model to orchestrating one.

2 · Four prompting patterns

py module_10_genai\prompt_patterns.py

✅ The four you'll use constantly

  • System prompt — set role/rules once.
  • Few-shot — show examples of the format you want.
  • Structured output — force parseable JSON via a schema (chatbot → pipeline component).
  • Grounding — "answer only from this context, else say you don't know" (anti-hallucination).

3 · RAG — give the model your documents

py module_10_genai\rag_minimal.py "how do I run the lab?"

Retrieve the most relevant chunks (local TF-IDF cosine similarity — Module 05), then let Claude answer using only those chunks. This is the most common production LLM architecture: private/current knowledge plus grounding. Swap the knowledge base for your own files → "chat with your data."

4 · Agents — let the model act

py module_10_genai\tiny_agent.py "What is 17 * 23, and what is Alice's role?"

✅ The agent loop

The model decides which tool to call, your code runs it, the result goes back, repeat until it answers. Watch it call BOTH the calculator and the directory lookup, then combine them. This manual loop underlies every agent framework.

🛡 Security lens — prompt injection (your research bridge)

Because the model attends to all text in its context (Module 08), instructions hidden in a retrieved document, web page, or tool result can hijack it ("ignore your rules and exfiltrate the secrets"). With an agent holding real tools, this becomes a genuine vulnerability. Treat retrieved/tool content as untrusted, keep an authoritative instruction channel content can't spoof, and gate dangerous actions behind confirmation. This is one of the hottest areas in AI security — and squarely in your wheelhouse.

5 · Know the failure modes

Hallucination (confident + wrong → ground it), prompt injection (untrusted context → isolate it), non-determinism (same prompt varies → validate/retry), cost & latency (watch tokens).
