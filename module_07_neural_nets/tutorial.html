✅ A neuron learns AND

Watch the loss fall and the trained neuron output ~0,0,0,1. A neuron is just the Module 02 dot product plus a squishing activation, trained by the Module 02 gradient descent. But it fails at XOR — a single neuron can only draw a straight line. That wall is why we need layers.

~60 lines of NumPy: forward pass, loss, backward pass (chain rule), update. This is the entire secret of deep learning. Once you've written it, no framework is a black box.

The chain rule walked link by link on the tiniest network, then verified against a numerical gradient — the real trick engineers use to debug autograd. If backprop feels mysterious, this notebook dissolves the mystery.

🛡 Security lens — adversarial examples

Because a network is differentiable, you can run gradient descent on the input to find a tiny, human-invisible perturbation that flips its prediction. That's an adversarial example — a direct consequence of the mechanism you just built. You'll reason about this in Module 09.
