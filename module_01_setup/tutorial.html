Environment Setup & How to Think Like an AI Engineer

Get a working toolchain, internalize the AI ⊃ ML ⊃ DL ⊃ GenAI hierarchy, and watch your first program learn.

⏱ ~45 min 🧩 No prior AI needed 💻 Runs 100% locally

1 · Where we're going

This module has three jobs: (1) make sure your computer can run everything in the course, (2) plant the single most important mental model in AI, and (3) let you see a machine learn with your own eyes. By the end you'll run two tiny programs and complete a sorting project that turns theory into instinct.

Before you read on

Open headfirst.md first if you haven't — it's the plain-English version of the big idea. This page is the hands-on walkthrough.

2 · Set up your environment

We use a virtual environment — a private sandbox of Python packages for this project, so the course never messes with the rest of your system.

Windows

py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py module_01_setup\setup_check.py

macOS / Linux

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python module_01_setup/setup_check.py

Or run the one-shot helper: run.bat (Windows) / make setup (mac/Linux).

✅ Try it — read the check

setup_check.py never installs anything; it just looks and reports. A healthy run looks like this: 

  Python 3.12   [OK]  (need >= 3.9)
  numpy   2.1.3 [OK]  used in M02
  pandas  2.2.3 [OK]  used in M03
  ...
  All set! You're ready for Module 01.

Anything marked MISSING prints the exact pip install line to fix it. Green all the way down = go.

3 · The Russian dolls (the model you must memorize)

Every buzzword you'll ever hear fits inside one of these four nested boxes:

AI ─ any trick that makes a machine seem smart └─ MACHINE LEARNING ─ learn the rule from DATA, not from hand-written code └─ DEEP LEARNING ─ ML with many-layered neural networks └─ GENERATIVE AI / LLMs ─ deep learning that CREATES (text, images, code)
LayerLearns rules from data?Example
Plain AI (rules)No — a human writes the rulesA thermostat; old chess engines
Machine LearningYesSpam filter; price predictor
Deep LearningYes, via neural netsFace recognition; speech-to-text
Generative AI / LLMsYes, and it generatesClaude; image generators

4 · The loop under everything

All learning systems run the same four-step cycle. Memorize this and the whole course becomes variations on a theme:

   DATA  ──▶  MODEL  ──▶  PREDICTION  ──▶  FEEDBACK (how wrong?)
     ▲                                          │
     └──────────────── adjust ◀─────────────────┘
                (repeat thousands of times)

5 · Watch a machine learn

hello_ai.py is ~40 lines of pure Python — no libraries. It is given pairs like (1,2), (2,4), (3,6) and must discover the hidden rule y = 2·x. It is never told the "2." It starts by guessing 0.0 and nudges toward the truth. 

py module_01_setup\hello_ai.py

✅ Try it — watch the guess crawl to 2.0

step |  w (our guess) | total error
   1  |        0.44000 |   220.00000
  30  |        1.99884 |     0.00012
  60  |        2.00000 |     0.00000
 ...
Learned rule: prediction = 2.0000 * x

That column of shrinking error is learning. The model found the "2" by itself. Now open the file and read the comments — you'll recognize all four loop steps labeled in the code.

Question to sit with

Change learning_rate = 0.01 to 0.5 and re-run. What happens? (Hint: too big a nudge overshoots — the guess bounces around or explodes.) This is your first taste of a hyperparameter, a knob you tune. You'll meet many more.

6 · Your project

Open project.md ("Is it AI?"). You'll take 12 real systems — a thermostat, a spam filter, Claude, a Roomba, a recommendation feed — and sort each into the correct Russian doll, writing one sentence of justification each. It's short, but doing it out loud is what converts the diagram into instinct.
