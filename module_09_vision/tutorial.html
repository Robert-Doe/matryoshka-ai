Computer Vision (Teaching Machines to See)

Images are grids of numbers. Convolution slides pattern detectors over them. CNNs learn those detectors from data. Then: adversarial examples.

⏱ ~2 hrs🖼 pixels → convolution → CNN 🛡 adversarial ML

1 · An image is an array

py module_09_vision\pixels_demo.py

✅ See the picture inside the numbers

A grayscale image is a 2-D array (0–255); color is 3 stacked grids (R,G,B). Editing = array math (brighten, invert, threshold). A phone photo is just HxWx3 numbers. Once you accept this, vision stops being magic.

2 · Convolution: the core operation

py module_09_vision\convolution_demo.py   # writes plots/convolutions.png

A kernel is a small grid of weights slid across the image; at each spot it computes a dot product (Module 02). Different kernels detect edges, blur, or sharpen. Open the PNG — the Sobel kernels light up edges. Each kernel is a feature detector.

3 · CNNs learn their own kernels

pip install torch
py module_09_vision\cnn_classifier.py

✅ The breakthrough

A CNN doesn't use hand-designed kernels — it learns them by backprop (Module 07). Weight sharing (same kernel everywhere) makes it efficient; hierarchy (edges → shapes → objects) makes it powerful. (torch guarded — prints install instructions if absent.)

4 · See what the filters detect

jupyter notebook module_09_vision\see_the_filters.ipynb

Runs without torch. Applies a bank of filters to a digit and shows each one's activation map glowing exactly where its pattern (vertical edge, diagonal, blob) appears. That's what a conv layer computes.

🛡 Security lens — adversarial examples (your bridge to AI security)

Because a CNN's output is a differentiable function of pixels, you can run gradient descent on the input to find a tiny, invisible perturbation that flips the prediction (FGSM/PGD). Stop sign → speed-limit sign. This is the whole field of adversarial ML — attacks and defenses — and one of the most natural AI↔security research bridges. This module gives you the mechanism.
